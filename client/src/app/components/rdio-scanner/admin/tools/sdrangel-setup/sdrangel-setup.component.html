Getting started

  1. Enable the SDRangel Bridge in Config → Bridge and add your channels. Set Binary Path (native) or Container Name (Docker) there too.
  2. Use the Service controls below to start sdrangelsrv.
  3. Click Provision SDRangel once it's running to push your channel config.
